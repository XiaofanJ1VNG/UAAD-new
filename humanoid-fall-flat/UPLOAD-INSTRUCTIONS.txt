Humanoid: Fall Flat / Robotic Failures

包含 20 件作品：
Failure in Life：4
Failure in Olympics：13
Failure on Stage：3

使用方法：
1. 解压这个 ZIP。不要把 ZIP 本身上传到网站。
2. 把 media 文件夹内的文件复制到 UAAD 仓库的 gallery/media/ 中。
   如已有 media 文件夹，合并其中的文件，不要删除原有媒体。
3. 把 works.json 放到 gallery/works.json。
   注意：这个 JSON 只包含本次 20 件作品。如果已有其他作品，请合并两个数组，不要覆盖已有作品记录。
4. 保留现有 index.html、admin.html、gallery.js、styles.css。
5. 在 UAAD 仓库目录中执行：
   git add gallery/media/ gallery/works.json
   git commit -m "Add robotic failure archive media"
   git push origin main
6. 等 GitHub Pages 部署完成后，打开 https://uaad.art/gallery/。
   建议先用无痕窗口确认，确保看到的是公开文件，而不是旧的本地浏览器副本。

如果你的常用浏览器仍只显示之前手动上传的作品：
现有代码会优先读取本地保存的作品清单。先通过管理页面 Export archive 备份原内容，
然后在管理页面 Import archive backup 中导入本次 works.json，刷新 gallery 即可。
不要清空整个浏览器数据，否则可能丢失原有投票和上传文件。
其他没有本地副本的访客会直接读取网站上的 works.json。

媒体说明：

文件路径改为小写英文及连字符，避免空格和引号造成路径问题。
视频未重新压缩，未改变画质或音轨；仅将 MP4 索引移到文件开头以便网页播放。
GIF 保留原文件与动画。
未指定封面，视频使用自身帧画面并按现有 gallery 代码静音循环播放。
未提供的艺术家、描述、来源链接和来源署名均留空。
投票仍然只保存在每个浏览器里，不会全平台汇总。
本包只包含媒体和作品清单，不会更改页面布局、密码或投票设置。
